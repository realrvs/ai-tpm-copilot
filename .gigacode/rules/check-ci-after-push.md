# Проверка статуса GitHub Actions после завершения работы

После завершения написания кода и выполнения `git push` в удалённый репозиторий необходимо:

1. Определить ветку, в которую был выполнен push, и получить ID последнего запуска workflow через `gh run list`:
   `gh run list --branch <ветка> --limit 1 --json databaseId -q ".[0].databaseId"`
2. Использовать полученный ID для отслеживания статуса запуска (блокирующее ожидание до завершения):
   `gh run watch <ID> --compact --exit-status`
3. Если exit code равен 0 (успех) — сообщить пользователю, что CI прошёл.
4. Если exit code не равен 0 (ошибка) — выполнить:
   `gh run view <ID> --log-failed`
   и на основе вывода лога объяснить причину ошибки и предложить исправление.
5. Если `gh` не авторизован или запуск не найден — сообщить пользователю о невозможности проверки и предложить сначала выполнить `gh auth login` или проверить вручную.
